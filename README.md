# SkyStore

-- это учебный интернет-магазин, разработанный в рамках курса по Django. 
Проект создан для отработки навыков работы с маршрутизацией, шаблонами и контроллерами.

## Технологии
- Python 3.10+
- Django 4.2


## Структура проекта

skystore/ # Корневая папка проекта
├── catalog/ # Приложение "Каталог"
│ ├── templates/
│ │ └── catalog/
│ │ ├── home.html # Главная страница
│ │ └── contacts.html # Страница контактов
│ ├── urls.py # Маршруты приложения
│ └── views.py # Контроллеры
├── config/ # Настройки проекта
│ ├── settings.py
│ ├── urls.py # Главные маршруты
│ └── wsgi.py
├── venv/ # Виртуальное окружение (не в репозитории)
├── .gitignore # Исключения для Git
├── manage.py # Управляющий скрипт Django
└── requirements.txt # Зависимости проекта
